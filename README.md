# 3분할 운동일지 (웹앱)

## 사용법 한눈에

- **요일 고정 없음**: 가슴 → 광배 → 하체 → 어깨 → 승모 순서로 돌아가요. 운동하는 날 "다음 차례 추천"을 누르거나, 원하는 세션을 직접 고르면 됩니다.
  고르지 않은 날은 휴식이고, 다음 추천은 마지막으로 한 세션 다음부터 이어져요. 3일 연속 운동하면 휴식을 권해요.
- **세션 변경**: 이미 고른 세션은 "세션 변경"으로 바꾸거나 휴식으로 돌릴 수 있어요.
- **오늘 목표**: 지난 기록을 보고 다음 목표를 제안해요. 목표 반복 상단에 도달하면 증량(예: 벤치 8회 → +5kg), 아니면 같은 무게로 1회 더.
- **세트 목표**: 종목마다 목표 세트 수가 있고(루틴 탭에서 변경), 횟수를 입력해 목표를 채우면 자동으로 완료 체크돼요.
- **백오프·드롭 자동 무게**: 탑세트 다음 세트는 탑의 약 87.5%, '+ 드롭'은 직전 세트의 약 80% 무게로 채워져요. 횟수는 한 만큼 직접 입력해요.
- **지난번 세트 비교**: 지난번에 한 세트 전체가 위에 보이고, 입력 칸에 지난번 같은 세트 숫자가 흐리게 표시돼요.
- **신기록(PR)**: 지난 기록보다 무겁거나 추정 1RM이 높은 세트에 PR 표시가 붙고, 기록 탭 '최근 신기록'에 모여요.
- **백업 알림**: 마지막 백업 후 2주가 지나면 운동 화면 위에 알려 드려요.
- **휴식 타이머**: 횟수를 입력하면 종목별 휴식 시간(메인 2:30, 보조 1:00~1:30) 타이머가 자동으로 시작돼요. 끝나면 소리가 나요(무음 모드에서는 안 들릴 수 있어요).
- **세트 종류**: 세트 번호를 누르면 탑 → 드롭 → 웜업. 웜업 세트는 볼륨·최고 기록에서 빠져요.
- **종목 교체**: 기구가 차 있으면 대체 종목(영상에 나온 것)이나 직접 입력한 종목으로 바꿔요. 기록은 종목 이름별로 따로 쌓여요.
- **루틴 탭**: 세션별로 종목을 추가·수정·삭제하고 ↑↓로 순서를 바꿀 수 있어요. 반복 범위·증량 단위·휴식 시간·대체 종목도 여기서 정해요. 세션 이름도 바꿀 수 있고, 언제든 영상 기본 루틴으로 되돌릴 수 있어요. 지운 종목의 기록은 기록 탭에 남아요.
- **기록 탭**: 최근 4주 부위 균형(오래 안 한 부위는 주황색), 종목별 최고 무게 추이, 날짜별 상세와 추정 1RM.

아이폰 홈 화면에 앱처럼 설치해서 쓰는 운동일지입니다. 한 번 열고 나면 인터넷이 없어도 열려요.
기록은 **그 휴대폰 안에만** 저장되니, 가끔 앱 아래쪽 "기록 백업 파일 저장"으로 백업해 두세요.

## 처음 올리는 방법 (GitHub Pages, 무료, 약 10분)

이미 올려 두셨다면 맨 아래 "업데이트하는 방법"만 보세요.

1. https://github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 **+ → New repository**를 누릅니다.
   - Repository name: `workout` (원하는 이름, 영어로)
   - **Public** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 압축을 푼 폴더 안의 내용을 **그대로** 끌어다 놓습니다.
   (`index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, `icons` 폴더)
   → 아래 **Commit changes**를 누릅니다.
5. 저장소 위쪽 **Settings → 왼쪽 Pages** 메뉴로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
6. 1~2분 기다린 뒤 Pages 화면을 새로고침하면 주소가 나옵니다.
   예) `https://아이디.github.io/workout/`

## 아이폰에 설치

1. 위 주소를 **Safari**로 엽니다. (Chrome에서도 공유 → 홈 화면에 추가로 됩니다)
2. 공유 버튼 → **홈 화면에 추가** → **추가**
3. 이제 홈 화면의 빨간 원판 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다.

## 알아두면 좋은 것

- **기록 위치**: 홈 화면 앱 안에 저장됩니다. Safari로 따로 연 페이지와는 기록이 따로예요.
  홈 화면 아이콘으로만 쓰는 걸 추천해요.
- **백업**: 백업 파일에는 기록과 직접 바꾼 루틴이 함께 들어가요. "기록 백업 파일 저장"을 누르면 공유 창이 뜹니다. "파일에 저장"이나 메모, 카톡 나에게 보내기 등으로 보관하세요.
  휴대폰을 바꾸거나 앱을 지웠다 다시 깔았을 때 "백업 파일 불러오기"로 되살릴 수 있어요.
- **루틴 수정은 앱 안에서**: 종목 추가·수정·삭제는 루틴 탭에서 하면 되고, 코드를 고칠 필요가 없어요.
  코드(`index.html`)를 직접 고쳐서 다시 올릴 때만 `sw.js` 맨 위의 `split3-v5`을 `split3-v6`처럼 숫자를 올려 주세요.
- 루틴 출처: 이도황 「더 큰 프레임과 사이즈를 위한 3분할 루틴」 https://www.youtube.com/watch?v=hIJhYHw7vSA

## 업데이트하는 방법 (이미 올려 둔 경우)

1. GitHub 저장소에서 **Add file → Upload files**를 누릅니다.
2. 새 압축 파일의 `index.html`, `sw.js`, `README.md`를 끌어다 놓고 **Commit changes**를 누릅니다. (같은 이름은 덮어써져요)
3. 1~2분 뒤 휴대폰에서 앱을 열었다 완전히 닫고 다시 열면 새 버전이 나와요.
   기존 기록은 그대로 남고, 예전 요일별 기록은 해당 세션으로 자동 인식됩니다.

## 아이콘을 바꿨을 때

아이폰은 홈 화면에 추가하는 순간의 아이콘을 계속 써요. 새 아이콘으로 바꾸려면 다시 추가해야 하는데,
**홈 화면 앱을 지우면 그 안의 기록도 함께 지워지니** 꼭 아래 순서대로 하세요.

1. 앱 → 기록 탭 → 맨 아래 **기록 백업 파일 저장** → '파일에 저장'으로 보관
2. GitHub에 `icons` 폴더와 `sw.js`를 올리고 1~2분 기다리기
3. 홈 화면 아이콘 길게 누르기 → 앱 삭제
4. Safari로 주소 다시 열기 → 공유 → 홈 화면에 추가
5. 새 앱 → 기록 탭 → **백업 파일 불러오기** → 1번 파일 선택 (기록과 직접 바꾼 루틴이 모두 돌아와요)
